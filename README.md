# FinalYearProject
This repository covers the code for my final year project titled "Strategy Clustering and Opponent Modelling in microRTS using Game Trace Data"
If you want to use the Bot, make sure to download the microRTS repository https://github.com/Farama-Foundation/MicroRTS and update the experimenter class.
If you want to perform runtime testing of the bot through the GUI, update the corresponding trace collection section to allow for runtime saving of the file.
Make sure all code within myBot.java points to files within your directories.
